# ADR-001: MCP / JSON-RPC 2.0 как протокол взаимодействия

**Статус:** принято  
**Дата:** 2025-04

## Контекст

Система должна интегрироваться с AI-ассистентами (Claude Desktop, OpenCode, Cursor).
Нужен стандартный протокол, который эти клиенты понимают нативно.

## Решение

Использовать **Model Context Protocol (MCP)** поверх JSON-RPC 2.0.

Поддержать два транспорта:
- **stdio** — основной для AI-ассистентов (Claude Desktop, OpenCode)
- **HTTP** — для CI/CD и прямых HTTP-клиентов

## Обоснование

- MCP — открытый стандарт Anthropic, нативно поддерживается целевыми клиентами
- JSON-RPC 2.0 — простой, текстовый, хорошо отлаженный протокол без бинарной сложности
- stdio-транспорт не требует сетевой конфигурации — процесс запускается клиентом напрямую
- HTTP-транспорт даёт возможность CI-интеграции без изменения кода

## Рассмотренные альтернативы

**gRPC:** бинарный протокол, не поддерживается AI-клиентами нативно, избыточная сложность.  
**REST:** не стандартизирован для tool-calling, каждый клиент реализовал бы по-своему.  
**GraphQL:** избыточен для простой схемы запрос/ответ.

## Последствия

- Обязательная поддержка методов `initialize`, `tools/list`, `tools/call`
- stdio-режим: один процесс на клиента, нет shared state между сессиями
- HTTP-режим: нет state между запросами — сервер stateless
